ことばを、紡ぐ。
文脈を読む日本語入力。

Tsumugi は、小さな LLM を内蔵した macOS の日本語入力メソッドです。書いている文章を読んで同音異義語を選び、続きを先読みし、取り違えを後からそっと指摘します。変換も学習も、すべてこの Mac の中で行います。

macOS 13 以降・Apple Silicon オフラインで動く オープンソース (MIT) v0.5.0
インストールする リリースノート

できること

ふだんどおりローマ字で打つだけ。必要なときだけ、小さく手を貸します。

打ったそばから漢字になり、文脈で選び直す

変換の土台は、自作の変換コア (ラティス + Viterbi) と Mozc の辞書。そこに超小型の言語モデル zenz (74MB) が加わり、カーソルより前の文章を読んで同音異義語を選びます。

前に「原稿の誤字を直したので、」と書いてあれば、「こうせい」は「校正」に。1 回 10〜30ms で、打鍵を待たせません。

候補は Space で開き、← → で文節を移り、Shift+← → で区切りを伸び縮みさせます。

原稿の誤字を直したので、校正
1構成
2校正
3厚生
4公正

続きが言い切れるときだけ、Tab で先読み

入力の履歴と LLM から、続きを予測します。確かなときだけ、カーソルのそばに小さく出します。Tab で確定、無視して打ち続ければ消えます。

予測は、書いている文書の文脈と、自分の書き癖を踏まえます。よく書く挨拶やいつもの言い回しほど、少ない打鍵で書けるようになります。

資料をお送りいただき、ありが
✦ありがとうございますtab

取り違えを、後からそっと指摘

文がひとまとまりになって手が止まったとき、文全体を読み直します。「仕様率 → 使用率」のような同音の取り違え、変換し忘れ、「をを」のような助詞の重複、「行きした」のような脱字を見つけたら、小さく提案します。

Tab で反映。無視すれば消え、3 回見送った提案は二度と出しません。言い回しや文体には手を出しません。

入力先の文章を読めないアプリでは出ません。

CPU の仕様率が高い
✎の仕様率→の使用率tab

英単語も、切り替えずにそのまま

日本語モードのまま英単語を続けて打てます。自分が書いたことのある語、大文字ではじめた語、ローマ字にならない綴りを英字とみなします。

英字と日本語のあいだ、数字と日本語のあいだには、打ち忘れた空白を自動で補います (「Tab で直す」「3 件」)。外れたときは英数キー (Ctrl+L / F10) で直せば、次からはその語も英字になります。

打鍵: tabdenaosu
Tab で直す
打鍵: NYryokou
NY 旅行

使うほど、自分の入力になる

選び直した変換、確定した言い回し、続けて打つ句のつながり、読みの並び (書き癖) を覚えます。学習はいつでも一時停止でき、まるごと消せます。

選

選び直した変換は、次から最初に出る

癖

よく打つ句のつながりを先読みに生かす

止

学習は入力メニューから一時停止できる

消

学習内容は 1 ファイル。いつでも全消去

プライバシー

入力内容を、ネットワークに送る処理はありません。

端末内

変換・予測・学習はすべて Mac の中。LLM も Mac の上で動きます。

読むだけ

先読みと直しのため、カーソルより前の文章 (最大 300 字) を読みます。メモリ上で使うだけで、保存しません。

1 ファイル

学習内容は user_model.json の 1 ファイルだけ (本人のみ読み書き可)。入力メニューから消せます。

打った文章の記録 (ふだんは無効)
入力メニューの「打った文章を記録する」を有効にしたときだけ、入れた文字・削除キーの回数・反映した直し・改行する直前の文章を ~/Library/Application Support/Tsumugi/writing/ に残します。文体の直しを作るための材料で、どこにも送りません。パスワード管理アプリでは記録せず、「記録した文章を消去…」でいつでも消せます。

パスワード欄では、macOS の仕様で入力メソッドそのものが呼ばれません。

インストール

いまは個人開発の試作段階です。署名済みのインストーラはまだないため、ソースからビルドします。

必要なもの: Apple Silicon の Mac (M1 以降)、macOS 13 以降、Xcode (Swift 5.9 以降)、python3、cmake (なければ Homebrew で入れます)。ダウンロードとビルドで 10 分ほど、空きは約 1.5GB 要ります。

curl -fsSL https://raw.githubusercontent.com/Anieca/tsumugi/main/install.sh | sh

辞書・モデル・llama.cpp を用意してビルドし、~/Library/Input Methods に入れて入力ソースとして有効にします。終わったら、メニューバーの入力メニューから Tsumugi を選んでください。一覧に出ないときは、一度ログアウトしてログインし直します。

  • 更新: 同じコマンドをもう一度実行します。版を指定するなら TSUMUGI_REF=v0.5.0 を付けます。
  • 削除: sh ~/.local/src/tsumugi/scripts/uninstall.sh (学習内容も消すなら --purge)

キー操作

キーはたらき
文字ローマ字入力。打つそばから変換される
Tab先読みを確定 / 直しの提案を反映 (どちらも、出ているときだけ。出ていなければアプリへ渡す)
Space候補を開く / 次の候補
← → / Shift+← →文節の移動 / 伸縮
Enter / Esc確定 / 取り消し
F6 F7 F10
(Ctrl+J K L)		ひらがな・カタカナ・英数。英数は末尾の語を英単語にする (続けて押すと語のはじまりが変わる)

先読み・直しの提案・空白の補い・英単語の扱い・学習・文章の記録は、どれもメニューバーの入力メニュー (「つ」の印) から切り替えられます。
